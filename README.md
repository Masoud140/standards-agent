# standards-agent

Retrieval and design-basis assistant over the firm's licensed Australian standards and
transport-authority documents. Companion to `Masoud140/pdf2bim-platform`; merged later as
`pdf2bim-platform/standards_agent/`.

- Start here: `docs/CURRENT_STATUS.md`, then `docs/NEXT_SESSION.md`.
- Rules: quote never recall; AI sets at most `transcribed-unverified`; authority rules separate
  from the standard; no standard PDFs or extracted text in this repository.
- Branches: feature branches only; never push to `main`.
- Tests: `python3 -m pytest tests/`
